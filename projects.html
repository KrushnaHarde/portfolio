FlashFlow — High-Concurrency Flash Sale Engine
GitHub Repository ↗
10,000+ Concurrent Requests 5,000 RPS p95: 384 ms 0% Error Rate

Engineered a high-concurrency flash-sale backend designed to handle extreme purchase request spikes while guaranteeing zero overselling and ultra-low latency execution under heavy stress testing.

Technical Highlights:

  • Redis Lua Atomic Reservations: Implemented atomic inventory checking & reservation in Redis Lua scripts to eliminate race conditions under concurrent purchase attempts, enforced by two-layer idempotency (Redis SETNX + DB constraints).
  • Asynchronous Kafka Order Pipeline: Built a decoupled Kafka order processing pipeline featuring sliding-window rate limiting and automatic TTL-based stock rollback for unfulfilled orders.
  • Load Testing & Benchmarking: Sustained 5,000 RPS with a p95 response time of 384 ms and a 0% error rate during k6 load testing under 10,000+ concurrent requests.
